# imper0502's 60-key keymap

## Keymap

```
LAYOUT_split_4x6_2x3
┌───┬───┬───┬───┬───┬───┐             ┌───┬───┬───┬───┬───┬───┐
│ « │ » │ @ │ # │ ( │ ) │             │ ^ │ & │ * │ $ │ins│del│
├───┼───┼───┼───┼───┼───┤             ├───┼───┼───┼───┼───┼───┤
│tab│ q │ w │ f │ p │ b │             │ j │ l │ u │ y │- _│= +│
├───┼───┼───┼───┼───┼───┤             ├───┼───┼───┼───┼───┼───┤
│esc│ a │ r │ s │ t │ g │             │ m │ n │ e │ i │ o │' "│
├───┼───┼───┼───┼───┼───┤             ├───┼───┼───┼───┼───┼───┤
│alt│ z │ x │ c │ d │ v │             │ k │ h │, <│. >│/ ?│\ |│
└───┴───┴───┴───┴───┴───┘             └───┴───┴───┴───┴───┴───┘
                ┌───┬───┬───┐     ┌───┬───┬───┐
                │ctl│sft│bs │     │ent│spc│` ~│
                ├───┼───┼───┤     ├───┼───┼───┤
                │a+s│c+a│c+s│     │fCA│fCS│fAS│
                └───┴───┴───┘     └───┴───┴───┘
```

`esc` is a mod-tap (gui) and `'` taps a quote and holds Win with the `_FN` layer. `sft` is the Shift tap dance. `ent` taps Enter and holds Shift with the `_FN` layer, `spc` taps space and holds the `_FN` layer, and ``` ` ~ ``` taps a grave and holds Ctrl with the `_FN` layer. The lower thumb row is `Alt+Shift`, `Ctrl+Alt`, `Ctrl+Shift`, and the `_FN` layer held with Ctrl+Alt, Ctrl+Shift, or Alt+Shift.

No keyboard in this userspace uses `LAYOUT_split_4x6_2x3` yet, so this keymap is not built by any target.
