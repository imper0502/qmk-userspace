# The imper0502 keymap for pragmatic_classical

The `split_4x6_4` keymap placed in the middle of the 72 keys: the four main rows sit on rows 2 to 5 and the eight thumb keys on row 6. The outer keys and the first row are unassigned. Shared code and the feature switches live in `users/imper0502`, see its readme.

```sh
qmk compile -kb pragmatic_classical -km imper0502
```
